2. Detailed Error & Defect Investigation Report
As per your strict instructions ('Just tell me what errors are there, don't fix anything. Let me know first'), here is the exact
list of errors and missing capabilities discovered:
Issue 1: Email Sharing Functionality Failure ('I am not able to share any emails')
 Root Cause 1 — Missing UI Action Button: In the Patient Portal (`/records`, `/reports`, `/timeline`) and Doctor Portal
 (`/doctor/patient-detail`), there is no 'Share History via Email' button or email dialog.
 Root Cause 2 — Unconfigured SMTP Credentials: In backend/config/settings.py, EMAIL_HOST_USER and
 EMAIL_HOST_PASSWORD are empty in .env. Django falls back to console.EmailBackend, which prints emails to the
server console log instead of delivering them to real inbox addresses.
 Root Cause 3 — Missing API Endpoint: There is no Django view (e.g. POST /api/reports/share-email/) to generate PDF
 summaries and dispatch them to recipient email addresses.
Issue 2: Surgery & Operative Procedure Recording Gaps ('Doctor doing patient's surgery')
 Root Cause 1 — Missing Dedicated Surgery Module: There is no dedicated Surgery / Operative Note form or model in
 the backend or frontend.
 Root Cause 2 — Hospital Admission Model Limit: In backend/apps/hospital/models.py, InpatientAdmission only records
 basic ward fields (diagnosis, ward, bed_no, discharge_notes). It lacks fields for procedure name, operating surgeon,
anesthesia type, and operative findings.
 Root Cause 3 — Medical Record Type Limit: In backend/apps/reports/models.py, MedicalRecord types are limited to:
 Prescription, Discharge Summary, Doctor Note, Lab Report. There is no explicit Surgical Note / Operative Report type.
Issue 3: Diagnostic Lab & Hospital Module Simulated Counters
